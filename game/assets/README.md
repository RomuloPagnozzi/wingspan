# game/assets

Serialized card data loaded at runtime by the registry in `core/models.py`.

## Files

| File | Contents |
|------|----------|
| `birds.pickle` | all bird cards as `BirdCard` frozen dataclasses |
| `bonuses.pickle` | all bonus cards as `Bonus` frozen dataclasses |
| `powers.pickle` | power definitions keyed by bird ID |
