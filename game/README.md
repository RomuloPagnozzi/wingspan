# game

Core game logic for Wingspan.

## Files

| File | Contents |
|------|----------|
| `engine.py` | Main entry point `transition_state()`, turn lifecycle, power activation |
| `phase_handlers.py` | Phase-specific handlers (MAIN_TURN, PLAY_BIRD, etc.), `get_phase_handler()` |
| `actions.py` | Action generators per phase, `get_actions()`, `@action_generator` decorator |
| `effects.py` | Game effects: `draw_cards_effect()`, `lay_eggs_effect()`, `gain_food_effect()`, etc. |
| `utils.py` | Helpers: board queries, power triggers, deck management, player rotation |
| `scoring.py` | Score calculation: `update_player_scores()`, `update_round_goal_scores()` |

## Subpackages

| Package | Contents |
|---------|----------|
| `core/` | Game state structures, registries, state copying |
| `power/` | Power handlers, choice generators, validators |
| `assets/` | Pickle files for birds, bonuses, powers (generated by `raw/generate_assets.py`) |

## Dependencies

```
core/           ← stdlib only
power/          ← core, effects, utils
effects.py      ← core, utils
utils.py        ← core
scoring.py      ← core
actions.py      ← core, utils, power
phase_handlers.py ← core, effects, utils, engine
engine.py       ← core, scoring, utils, power, phase_handlers
```

## Usage

```python
from game.core import initiate_state
from game.engine import transition_state
from game.actions import get_actions

state = initiate_state(n_players=2)
actions = get_actions(state)
new_state = transition_state(state, actions[0])
```
